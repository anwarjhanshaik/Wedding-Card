# 📂 Digital Wedding Invitation Card

A premium, fully responsive digital wedding invitation card crafted purely with semantic HTML5 and standard CSS3. Designed with a mobile-first approach, this template provides a seamless user experience across all devices, digital screens, and physical print mediums.

Live Demo: [https://anwarjhanshaik.github.io/Wedding-Card/]

---

## ✨ Key Features

* **📱 Universal Responsiveness**: Built with robust media queries optimized for mobile, tablet, and desktop screens.
* **🌙 Native Dark Mode**: Utilizes system-level user preferences (`prefers-color-scheme`) for comfortable low-light viewing.
* **🖨️ Clean Print Engine**: Custom `@media print` styles that automatically strip web elements (buttons, navigation) to generate a clean, elegant paper keepsake.
* **📍 Direct Venue Routing**: Embedded, lightweight hyperlinking to direct guests straight to navigation maps.
* **⚡ Zero Dependencies**: Pure HTML and CSS layout. No Javascript libraries, frameworks, or preprocessors required.

---

## 🛠️ Built With

* **HTML5**: Semantic markup for high accessibility and structural clarity.
* **CSS3**: Layout design using standard Flexbox, Grid, and native media queries.

## 🚀 How to Use & Customize

### 1. Clone the Repository
```bash
git clone https://github.com
```

### 2. Edit the Content
Open `index.html` in your text editor and update the text placeholders:
* Bride and Groom names
* Date, time, and ceremony details
* Venue address and navigation map links

### 3. Update the Styling
Open your CSS file to change colors, fonts, and backgrounds directly within the standard selectors (like `body`, `h1`, or specific class names) to match your wedding theme.

---

## 🖨️ Printing Instructions

To save or print a physical copy of this invitation:
1. Open the live link in any desktop web browser (Chrome, Safari, Edge).
2. Press `Ctrl + P` (Windows) or `Cmd + P` (Mac).
3. The custom print queries will automatically format the page into a clean layout.
4. Set the print destination to **Save as PDF** or select your physical printer.
